### Hosted defects discovered and fixed (all Class A, retained in source)

| # | Defect | Root cause | Fix | Verification |
| --- | --- | --- | --- | --- |
| D1 | intra-function calls 401 on hosted | Kong gateway requires `apikey`; local Edge Runtime does not gate | `apikey: Env.SUPABASE_ANON_KEY` added to both internal fetch headers in `run-cron-minute` (publishable key; target functions still enforce `X-Cron-Secret` — no auth bypass) | redeploy; workers then claimed/failed/retried live jobs |
| D2 | every scheduler response recorded `Timeout of 8000 ms` after D1 fix | migration 53 budgeted pg_net at 8s, sized for the pre-fix fast-401 path; real work = tasks + reminders(≤8s) + worker(≤10s) + health exceeds 8s | additive migration **57**: fire budget 8s → 20s (function body verbatim; explicit REVOKE/GRANT restated per F16-04) | 200s resumed at next tick; ACL re-verified in catalog |
| D3 | `queue_metrics_snapshots` writes fail every minute (stalled at 17:19 UTC) | `get_queue_health()` computes `now() - MIN(scheduled_at)` over PENDING jobs; retry backoff and reminder scheduling legitimately put `scheduled_at`/`scheduled_for` in the future → negative age → violates CHECK `>= 0`; NULL collapses to 0 for due-nothing sets | additive migration **58**: clamp at `INTERVAL '0 secs'` via GREATEST on both affected branches (body otherwise verbatim; boundary restated) | fresh snapshots resumed (15 rows/5 min); `metrics_snapshot: true` in function results; `pg_proc.proacl` shows service_role-only boundary intact |

D3 is data-state dependent, not staging-dependent: any production queue
holding one future-scheduled pending job starves the monitoring engine.
It never reproduced locally because local pending jobs all had past
`scheduled_at`.

Known non-fatal behavior (documented, not defect-fixed): the worker-trigger
fetch keeps its designed 10s `AbortSignal` budget and the minute body
sometimes records `"worker":"Signal timed out."` while the worker continues
server-side (heartbeats/claims remain fresh). Deliberately left as designed
client-side budget; changing it is a tuning decision, not a defect fix.
